Task: run v0.1.0 against the Sharf 2022 Dryad deposit as a machinery test on real
organoid units. Spontaneous recordings only; fixed-length epochs stand in for trials.
No changes under src/. Write scripts/sharf2022_g0.py (standalone, not part of the
package, not imported by tests) plus one unit test.

INPUT LAYOUT (verified, do not re-derive)
Root: data/sharf2022/kilosort2/
  7month/kilosort2/{2950,2953,2954,2957,5116,5118}.mat
  drug/kilosort2/control_{2950,2953,2954,2957}.mat
  interval/kilosort2/4hr_{1200,1600}_{2950,2957}.mat
Each .mat loads with scipy.io.loadmat(path, struct_as_record=False, squeeze_me=True)
and contains:
  units  - object ndarray of structs, fields: unit_id, electrode, spike_train,
           template, x_max, y_max
  fs     - sampling rate, scalar Hz
  locations - (n_electrodes, 2); per electrode, NOT per unit. Ignore it; use
           each unit's own x_max / y_max.
spike_train holds integer sample indices, not seconds. squeeze_me collapses a
one-element train to a scalar and an empty train to shape (0,), so wrap every
spike_train in np.atleast_1d before use.

Chip to organoid name, from README_organoid_data.txt:
  2953=L1  2950=L2  2957=L3  2954=L4  5116=L5  5118=L6

ARGUMENTS
--root (default data/sharf2022/kilosort2)
--out (default output/sharf2022)
--epoch-s (default 5.0)
--min-epochs (default 20)
--n-perm (default 1000)
--seed (default 42)

PER RECORDING
1. Load. duration_s = max spike sample over all units / fs.
   n_epochs = floor(duration_s / epoch_s). If n_epochs < min_epochs, skip the
   recording and record the reason in the summary; do not silently continue.
2. unit_id: str(int(unit.unit_id)) prefixed with "u". If those are not unique
   within a file, fall back to the position in the units array and say so in the
   summary for that recording.
3. Epoch k spans [k*epoch_s, (k+1)*epoch_s) in seconds. Spikes at or beyond
   n_epochs*epoch_s are dropped.
   trial_index = k; stim_time_ns = round(k * epoch_s * 1e9); condition = "spontaneous".
4. Measure, per (unit, epoch): firing_rate_hz = spike count / epoch_s.
   A unit with no spikes in an epoch scores 0.0, never null: zero spikes is a
   measurement, not a missing value (SPEC §15). Every unit therefore satisfies the
   inclusion rule, and no unit is filtered on activity — filtering on activity is
   the unit-selection attack in METHOD's gaming table.
5. Write to {out}/{stem}/:
   units.csv       unit_id, recording_id=stem, session_id=stem,
                   preparation_id=<organoid name>, x_um=x_max, y_um=y_max
   responses.csv   full unit x epoch grid
   spikes.csv      unit_id, spike_time_ns = round(sample / fs * 1e9)
   preparation.json  species "Homo sapiens", preparation_type "organoid",
                   age_days 210, age_basis "days_post_differentiation",
                   line_or_donor_id "F12442.4", instrument "MaxOne",
                   raw_data_url "https://doi.org/10.25349/D9031Z"
                   (development/ files would need a different age_days; they are
                   out of scope here, so hardcoding 210 is correct for this set.)
   conditions.json {"spontaneous": {protocol, compound, dose, dose_unit, vehicle
                   all null}} — these recordings have no commanded load.
6. Run the two commands a contributor runs, by subprocess, capturing JSON:
   rrb-check    <units> <responses> --measures firing_rate_hz
                --post-stim-window-s {epoch_s} --load-duration-s 0
                --preparation ... --conditions ... --spikes ... --json
   rrb-evaluate same arguments plus --n-perm and --seed
   Save both JSON documents under {out}/{stem}/. A nonzero exit is recorded in the
   summary, not swallowed.

OUTPUTS
{out}/g0.png — one panel per recording, odd-half against even-half mean
firing_rate_hz per unit, log scale on both axes with the identity line. Rebuild the
halves with evaluate.split_halves on the written responses.csv, taking active units
from the check report. Panel title:
"<organoid> <stem>: rho=<rho:.3f> [<lo:.2f>, <hi:.2f>], n_units=<n>, n_epochs=<n>".

{out}/summary.md — one row per recording: organoid, stem, duration_s, n_epochs,
units, units_included, conformance, rho, rho_ci_low, rho_ci_high, rho_at_20,
null_p95_rho, var_between, var_within, moments_reliability, r_undefined,
r_nonpositive, positive_control_passed, check_exit, evaluate_exit.

TEST
tests/test_sharf2022_g0.py, on a hand-built units list (3 units, fs=20000,
epoch_s=5.0, spikes placed by hand to span 17 s): asserts n_epochs == 3, exact
per-epoch counts, that an empty epoch yields 0.0 and not NaN, that a unit with a
single spike survives np.atleast_1d, and that stim_time_ns values are exact
multiples of 5e9. No dataset files in CI; the end-to-end run is manual.
