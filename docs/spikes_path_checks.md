# Spikes-Path Simulation Checks

Comparison of the within-session Spearman-Brown split-half reliability ceiling on pooled spike-train measures against two-session test-retest correlation across three synthetic 30-unit inhomogeneous Poisson populations (`i = 0..29`, recovery time constants `taus = np.geomspace(0.05, 0.5, 30)` s via `recovery_reliability_benchmark.synthetic.exponential_recovery` and `make_spike_trains`):

- **strong**: baseline `np.geomspace(1.0, 20.0, 30)[(7 * i) % 30]` Hz, peak `100` Hz.
- **weak**: same baselines as `strong`, peak `30` Hz.
- **sparse**: baseline `np.geomspace(0.2, 5.0, 30)[(7 * i) % 30]` Hz, peak `np.geomspace(5.0, 50.0, 30)[(11 * i) % 30]` Hz.

For each population, trial count `n_trials` in `(20, 40)`, and `seed` in `0..39` (40 seeds), with `AnalysisParams(post_stim_window_s=2.0)` and inter-stimulus interval `5.0` s: two independent sessions of the same units are simulated with `seed` and `10_000 + seed`. `unit_measures` is evaluated over all trial onsets of each session (`test_retest` = Pearson `r` across units non-NaN in both sessions) and over the first session's odd (`onsets[0::2]`) and even (`onsets[1::2]`) trial onsets (`r_half` = Pearson `r` across units non-NaN in both halves; `split_half_corrected = 2 * r_half / (1 + r_half)` if `r_half > 0` else `0`; `units_scored` = count of units non-NaN in both halves). Tables report the mean across the 40 seeds, generated by `python scripts/spikes_path_checks.py`.
